# Skill Template

Provide a clear, actionable summary of what this skill does and the specific workflows it enables.

## When to Use

- Explicit user triggers (e.g., "run my-skill", "how do I configure X")
- Scenarios where this skill should be automatically selected
- **Do NOT use** for scenarios handled by other specialized skills

## Workflow & Steps

1. **Step 1: Preparation**
   - Inspect files and verify prerequisites.
2. **Step 2: Execution**
   - Run commands or make targeted edits.
3. **Step 3: Verification**
   - Confirm observable outcomes and validate results.
